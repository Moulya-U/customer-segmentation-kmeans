# Customer Segmentation using K-Means Clustering

## Project Overview
This project uses K-Means clustering to segment customers based on their characteristics and spending behaviour.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Methodology
- Data preprocessing
- Data scaling
- Elbow Method
- K-Means clustering
- Customer segment analysis
- Data visualization

## Dataset
Mall Customers dataset.
